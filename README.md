# Бот-магазин (Telegram, aiogram 3)

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` (от @BotFather) и `ADMIN_ID` (ваш Telegram id).
3. `python main.py`

## Как работает
1. Клиент: Каталог → товар → «Оформить заявку» → имя, контакт, задача.
2. Бот отвечает клиенту: заявка отправлена, оплата после сообщения продавца.
3. Вам в личку приходит заявка с кнопкой «💰 Клиент оплатил товар».
4. После нажатия клиент получает запрос оценки 0–5 и может написать сообщение к отзыву.
5. Сделка попадает в меню «⭐ Завершённые сделки и отзывы» (видно всем).
6. «🔒 Безопасная сделка» — ссылка на ваш профиль Playerok и кнопка выхода в меню.

## Товары
Редактируются в `bot/products.py`.
